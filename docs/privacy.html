ことばめくり プライバシーポリシー

このプライバシーポリシー(以下「本ポリシー」といいます)は、iOS アプリケーション「ことばめくり」(以下「本アプリ」といいます)における情報の取り扱いについて定めるものです。

1. 基本方針

本アプリは、利用者のデータを端末の外へ送信しません。本アプリは、利用者に関する情報の収集を行いません。

当方はサーバーを持たず、本アプリが当方に対して情報を送信することはありません。氏名、メールアドレス、電話番号、住所、位置情報、端末を識別する情報、本アプリの利用状況のいずれについても、当方が取得することはありません。利用者に本アプリ上でアカウントを作成していただくこともありません。

ただし、本アプリが一切の通信を行わないわけではありません。Pro の購入および購入の復元を行う際には、本アプリは Apple Inc. の App Store と通信します。この通信は購入手続きのために Apple Inc. との間で行われるものであり、当方に情報が渡ることはありません。詳細は第5項に記載します。

2. 端末の中に保存される情報

本アプリは、利用者が設定し、また保存した内容を、その端末の中だけに保存します。保存する内容は次のとおりです。

  • 表示に関する設定 — テーマ、フォント、および表示する言葉の著者・作品・カテゴリの選択(絞り込みを変更した履歴を含みます。絞り込みは翌日から効くため、いつ何に変えたかを日付とともに保持します)
  • お気に入りとして保存された言葉
  • お気に入りに添えられたメモ
  • 通知に関する設定 — 通知の有無と、通知する時刻
  • Pro の購入状態
  • アプリの利用の状態 — 本アプリを最初に起動した日、および初回の案内や一度きりの案内を表示したかどうか

これらはいずれも、本アプリ本体とウィジェットが共有する端末内の保存領域(App Group の UserDefaults)に保存されます。端末の中に置かれるだけであり、当方や第三者に送信されることはありません。当方はこれらの内容を見ることができません。

これらの内容は、本アプリを端末から削除すると、あわせて削除されます。

3. iCloud バックアップについて

利用者が端末の iCloud バックアップを有効にしている場合、前項に挙げた端末内の保存内容が、端末のバックアップの一部として Apple Inc. の iCloud に複製されることがあります。

この複製は、本アプリが行うものではなく、iOS がバックアップの機能として行うものです。バックアップされた内容の取り扱いは、Apple Inc. の定めに従います。バックアップを行うかどうかは、iOS の「設定」アプリからいつでも変更できます。

4. 第三者への提供、解析、広告

当方は、利用者に関する情報を第三者に提供しません。提供する情報そのものを取得していません。

本アプリは、利用状況を計測する解析の仕組みを組み込んでいません。本アプリは広告を表示しません。本アプリは、利用者を追跡するための識別子を用いません。本アプリは、第三者が提供するライブラリや SDK を一切組み込んでいません。

本アプリには、言葉を検索する(Google)ために外部のウェブサイトを開く操作があります。この操作は、利用者がそれを押したときにだけ働き、アプリの中のブラウザ(iOS の Safari の機能)で開きます。開いた先のサイトでの情報の取り扱いは、そのサイトの方針に従います。本アプリがそのサイトへ、利用者や利用状況に関する情報を送ることはありません。

5. 購入に関する情報

Pro の購入手続きは、Apple Inc. の App Store を通じて行われます。お支払いに関する情報は Apple Inc. が取り扱い、当方には渡されません。当方は利用者のクレジットカード番号等の決済情報を受け取らず、保持しません。

本アプリが端末の中に保存するのは、Pro が有効であるかどうかという状態のみです。

6. このページについて

本ポリシーおよび利用規約のページは、GitHub Pages(GitHub, Inc.)によって配信されています。これらのページを閲覧された際の接続記録は、配信を行う GitHub, Inc. が保持することがあります。当方はその記録を取得せず、閲覧されたことを知る手段を持ちません。

本アプリの中からこれらのページを開いた場合、開かれるのは端末の標準のブラウザであり、これらのページの取得を本アプリが行うわけではありません。

7. 本ポリシーの変更

当方は、本アプリの機能の追加や変更にあわせて、本ポリシーを変更することがあります。変更後の本ポリシーは、このページに掲載した時点から効力を生じます。変更した場合は、このページの末尾に記載する最終更新日を更新します。
